# 🌷 Jardim de Flores

## Sobre o projeto

O Jardim de Flores é um site simples desenvolvido para cadastrar e visualizar flores favoritas. O projeto permite adicionar o nome e o tipo de cada flor, exibindo as informações em uma tabela organizada.

O site possui um visual delicado, com cores em tons de roxo e verde pastel, inspirado na natureza e nas flores.

## Tecnologias utilizadas

- **HTML:** estrutura da página.
- **CSS:** estilização, cores, bordas e organização dos elementos.
- **JavaScript:** funcionamento do formulário e cadastro das flores.

## Funcionalidades

- Cadastro do nome da flor.
- Cadastro do tipo da flor.
- Exibição das flores em uma tabela.
- Numeração automática das flores cadastradas.
- Limpeza dos campos após adicionar uma flor.
- Efeito visual no botão ao passar o mouse.

## Como executar o projeto

1. Abra a pasta do projeto no Visual Studio Code.
2. Verifique se os arquivos HTML, CSS e JavaScript estão na mesma pasta.
3. Abra o arquivo `index.html` no navegador.
4. Digite o nome e o tipo da flor nos campos.
5. Clique em **Adicionar flor** para inserir a flor na tabela.
